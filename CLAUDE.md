This repository hosts the Global Media Operations project.

If `.claude/skills/media-operations/SKILL.md` is not present, the full starter bundle has not yet been extracted into the repository root. Ask the user to add the contents of the starter ZIP before implementing the project.

Once the skill files are present, read the skill and its referenced playbooks before changing the project. Start with an audit and implement incrementally according to the roadmap.
