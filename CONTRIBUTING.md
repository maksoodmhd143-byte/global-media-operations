# Contributing

Contributions are welcome. Please keep changes focused, documented, and safe for a public repository.

## Before submitting

- Never include secrets, credentials, customer data, private messages, or real account configuration.
- Use synthetic examples in `*.example.*` files.
- Preserve platform-specific API restrictions and require authorised official integrations.
- Add tests or clear manual verification steps for implementation changes.
- Document limitations; do not claim an integration works until it has been tested end to end.
- Keep ADMINX and unrelated projects out of this repository.
- Do not enable live publishing, automated replies, spending, or external outreach by default.

## Pull requests

Explain the problem, the change, security/privacy implications, and how it was tested.
