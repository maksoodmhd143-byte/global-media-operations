# Global Media Operations

An open-source, free-first starter kit for building an AI-assisted media operations system.

## Scope

The project blueprint covers research, editorial planning, daily content production, graphics, short-form video, platform-specific publishing, analytics, trend and competitor intelligence, creative direction, audience intelligence, growth, revenue intelligence, operations, and 24/7 community management on officially supported platform surfaces.

**This is a starter kit, not a deployed service.** It does not yet include a running scheduler, hosted workers, connected social accounts, API approvals, credentials, or a finished rendering and publishing engine.

## Get the complete starter files

Download the `global-media-operations-public-release.zip` bundle from the project conversation, extract it, and copy the contents of its `global-media-operations/` directory into this repository root. The Claude Code skill will then be available at:

`.claude/skills/media-operations/SKILL.md`

## Use with Claude Code

1. Clone this repository.
2. Extract and copy the starter bundle into the repository root if it is not already present.
3. Run `claude` from the repository root.
4. Invoke `/media-operations`.
5. Start with a repository audit and implement Phase 1 only; do not connect or publish to social accounts yet.

## Security and privacy

- Never commit API keys, OAuth tokens, passwords, private keys, customer messages, personal data, or confidential brand information.
- Keep real settings in ignored local files or a secret manager; commit only example templates.
- Review changes before publishing and rotate any credential accidentally exposed.
- See [SECURITY.md](SECURITY.md) and [CONTRIBUTING.md](CONTRIBUTING.md).
